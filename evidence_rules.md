# TerraGuard AI — Evidence Assessment Rules

These are initial demo rules, not an official emergency-service standard.

1. Validate that each evidence item has a source and description.
2. Treat unverified community reports as unconfirmed, even when severity is high.
3. Give more confidence to evidence marked verified, while retaining its source.
4. If multiple independent sources support the same incident, flag it for review.
5. Never claim a disaster is confirmed solely from this sample data.
6. Output a transparent summary, evidence count, verification count, and recommended human follow-up.

## Safety

This prototype is for demonstration only. It must not replace official alerts, trained responders, or emergency services.
